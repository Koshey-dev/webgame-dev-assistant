# GamePush

## SDK · подключение скрипта в игру
Требование: чтобы использовать GamePush SDK, игру нужно добавить в панели GamePush, а скрипт SDK (из раздела Install Code проекта) вставить в index.html игры; для Construct 3 вместо этого ставят плагин C3 Plugin - GamePush с ID проекта и публичным токеном.
Цитата: Для использования возможностей GamePush SDK нужно добавить игру в панели.
Цитата: Для встраивания GamePush SDK в свою игру необходимо добавить скрипт в index.html игры.
Источник: https://docs.gamepush.com/ru/tutorials/publishing-the-game-on-platforms-guide/
Сверено: 2026-10-15

## SDK · колбэк onGPInit
Требование: работать с SDK нужно внутри функции-колбэка window.onGPInit, куда передаётся экземпляр GamePush SDK; в примере перед стартом игры ждут player.ready и прелоадер рекламы ads.showPreloader().
Цитата: Затем объявите функцию-callback, в которую будет передан экземпляр GamePush SDK.
Источник: https://docs.gamepush.com/ru/tutorials/publishing-the-game-on-platforms-guide/
Сверено: 2026-10-15

## SDK · определение площадки
Требование: GamePush SDK сам определяет площадку по URL, по косвенным признакам (GET-параметры, окружение) или по явному указанию площадки, и подгружает адаптер с SDK и настройками этой площадки.
Цитата: GamePush позволяет запускать вашу игру на множестве площадок, подключая все необходимые SDK площадок автоматически.
Цитата: По косвенным признакам (гет-параметры, окружение);
Источник: https://docs.gamepush.com/ru/docs/platforms/
Сверено: 2026-10-15

## SDK · проверка возможностей площадки
Требование: перед использованием чата и внешних backend-сервисов нужно проверять флаги gp.platform.isChatAvailable и gp.platform.isBackendAllowed: площадка может запретить чат и разрешать только офлайн-игру.
Цитата: Площадка разрешила или запретила использовать чат в игреgp.platform.isChatAvailable
Цитата: Площадка разрешает подключаться к внешним backend-сервисам или игра доступна только офлайнgp.platform.isBackendAllowed
Источник: https://docs.gamepush.com/ru/docs/platforms/

Цитата: Вызовите событие готовности игры gp.gameStart();, когда игра полностью загружена.

## Прочее · CoolMath события аналитики
Требование: для CoolMath вызывать gp.analytics.goal('LEVEL_START', 0) при нажатии «играть» при запуске, gp.analytics.goal('LEVEL_START', N) при старте уровня N и gp.analytics.goal('LEVEL_REPLAY', N) только при нажатии кнопки перезапуска уровня (автоперезапуск не отправляют).
Цитата: Вызовите событие gp.analytics.goal('LEVEL_START', 0);, когда игрок нажал на кнопку играть при запуске игры.
Цитата: Вызовите событие gp.analytics.goal('LEVEL_REPLAY', 123);, когда игрок нажимает начать уровень заново (начать заново, перезапустить, попробовать еще раз). 123 - номер уровня. Только при нажатии на кнопку. При автоматическом перезапуске уровня посылать событие не нужно.
