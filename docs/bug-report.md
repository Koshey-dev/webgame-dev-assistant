# Баг-репорт из игры

Кнопка «Сообщить об ошибке» в игре собирает техническое состояние и текст игрока и
отправляет одним JSON. В CRM он становится тикетом: CRM добавляет `id`, `created`,
`status` и находит игрока по id площадки. Ассистент поддержки читает тикет через
MCP-сервер CRM (`/mcp/support`: `ticket_list`, `ticket_get`, `player_get`).

Сейчас CRM — демо-файл `support/crm.json` (выдуманные игроки и тикеты на играх
проекта); настоящая подставляется путём в `SUPPORT_CRM`.

## Поля тикета

| Поле | Что это | Кто заполняет |
|------|---------|---------------|
| `id` | номер тикета, `T-…` | CRM |
| `created` | когда пришёл, ISO 8601 UTC | CRM |
| `status` | `open`, `answered`, `closed` | CRM |
| `player` | id игрока в CRM, `p-…` | CRM, по id площадки |
| `game` | slug игры: `coloring`, `mahjong1`, `mahjong`, `differences`, `word-solitaire` | игра |
| `version` | версия сборки, напр. `v32` | игра |
| `platform` | площадка: `vk`, `ok`, `yandex`, … | игра (SDK) |
| `sdk` | `GamePush` или `Yandex Games SDK` | игра |
| `lang` | язык интерфейса игры | игра |
| `device` | `os`, `browser`, `screen`, `touch` | игра |
| `state` | состояние игры: `auth` (вход на площадке), `level`, `no_ads` (куплено «Без рекламы»), `sound`, `music`, `last_save` (время последнего сохранения), `save` (`cloud` или `local`) и поля самой игры | игра |
| `errors` | последние ошибки JS и SDK: `at`, `text` | игра |
| `comment` | текст игрока | игрок |

## Чему верить

Баг-репорт собирает клиент, значит любое поле может прийти подделанным — не только
`comment`. Поэтому ассистент:

- обрезает каждую строку (комментарий — до 1500 символов, остальное — до 300),
  убирает управляющие символы и свои разделители `<<<` `>>>`;
- помечает текст, похожий на попытку управлять моделью («игнорируй инструкции»,
  «ты теперь…», `system:`), — пометка видна в чате и уходит модели;
- даёт модели тикет только как данные между разделителями и не даёт ей
  инструментов: данные других игроков ей недоступны;
- сверяет слова игрока с данными сам: «я вошёл» при `state.auth = false`,
  «купил» без оплаченной покупки в CRM;
- проверяет черновик ответа игроку: ссылки не из базы вырезаются, внутренние
  детали и обещания компенсаций помечаются.

## Пример

```json
{
  "id": "T-1001", "created": "2026-10-15T18:42:10Z", "status": "open", "player": "p-0001",
  "game": "mahjong1", "version": "v31", "platform": "ok", "sdk": "GamePush", "lang": "ru",
  "device": {"os": "Android 13", "browser": "OK app WebView 129", "screen": "393x873", "touch": true},
  "state": {"auth": true, "level": 57, "no_ads": false, "sound": true, "music": true,
            "last_save": "2026-10-15T18:40:02Z", "save": "cloud"},
  "errors": [],
  "comment": "Купила отключение рекламы, а реклама всё равно показывается"
}
```
